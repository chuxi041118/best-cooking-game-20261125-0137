Ember Kitchen Rush is a fast, original timed cooking game: pick orders off the board, click ingredients in recipe order to build each dish on the plate, and serve before the ticket timer runs out — a wrong ingredient costs 3 seconds.

## Run it

```sh
node serve.ts
```
Then open http://localhost:8080.
